# 🌲 Darkwood

**Сверхбыстрый визуальный помощник для поиска скрытых предметов**

## Главная идея

Вместо «насилования» процессора постоянным сканированием всего 4K-экрана через тяжелый OpenCV (как в Python), 
Darkwood использует **точечный мониторинг на Go**:

- ⚡ **Быстро**: Две легковесные горутины вместо тяжелых циклов
- 🎯 **Точно**: Проверка только заранее известных координат (ROI)
- 💾 **Легко**: Один `.exe` файл без зависимостей
- 🎮 **Удобно**: Прозрачный оверлей поверх игры

## Архитектура

### База знаний (JSON)
- 200+ локаций
- Для каждой локации:
  - **Якорь** — уникальный хеш угла экрана для автоопределения
  - **Хеши слов** — из списка заданий в подвале игры
  - **Координаты предметов** — ROI для точечной проверки

### Двойное «зрение» (Две горутины)

1. **TextScanner** (Сканер текста)
   - Раз в секунду сканирует «подвал» игры
   - Превращает картинку слова в 64-битный хеш
   - Определяет: «Ищем Яблоко и Кинжал»

2. **ItemFinder** (Поиск предметов)
   - Получает ID нужных предметов
   - Проверяет только конкретные точки на экране
   - Подтверждает: «Предмет на месте»

### Умный оверлей
- Прозрачное окно поверх игры
- Зеленые рамки вокруг найденных предметов
- «Стакан» — список найденного
- Таймер для азарта и статистики

### Режимы работы

| Клавиша | Режим | Описание |
|---------|-------|----------|
| **F1** | 🎮 Игра | Бот работает в фоне, подсвечивает предметы |
| **F2** | 📚 Обучение | Запоминание новых предметов и координат |

## Структура проекта

```
darkwood/
├── cmd/
│   └── main.go           # Точка входа
├── internal/
│   ├── config/
│   │   └── config.go     # Модели данных JSON
│   ├── vision/
│   │   ├── hasher.go         # Вычисление perceptual hash
│   │   ├── text_scanner.go   # Сканер текста (Горутина #1)
│   │   └── item_finder.go    # Поиск предметов (Горутина #2)
│   ├── overlay/
│   │   └── overlay.go    # Оверлей для отрисовки
│   └── game/
│       └── manager.go    # Менеджер режимов и состояний
├── go.mod
└── darkwood.exe          # Готовый бинарник
```

## Технические детали

### Perceptual Hash
- 8×8 grid = 64 бита
- Сравнение по XOR с подсчетом одинаковых битов
- Молниеносное сравнение: `hash1 ^ hash2`

### Производительность
- TextScanner: проверка каждые 1000ms
- ItemFinder: проверка каждые 500ms
- Overlay: обновление каждые 100ms
- Потребление RAM: < 50MB
- Нагрузка CPU: < 5%
